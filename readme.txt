A simple solution for creating, managing, and verifying School/Colleges certificates.

== Description ==

CertifyPress is a simple yet powerful WordPress plugin designed for schools and colleges to create, manage, and verify certificates.

Features:
- Custom Certificate Post Type
- Categories and Tags for organization
- Custom Fields support
- Frontend certificate search with shortcodes
- Bulk certificate management
- Draft and Publish status support

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/certifypress/`, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Certificates menu to manage your certificates.
4. Use shortcodes to display search forms on frontend pages.

== Frequently Asked Questions ==

= How do I add a certificate? =

Go to Certificates > Add Certificate and fill in the details.

= How do I search certificates on the frontend? =

Use the `[certificate_search]` shortcode on any page.
